# Retained art library

The owner reset the visual presentation on 2026-11-08. The old modular faces,
clothes, role sprites and UI assets have been deleted, including their rejected
character archives and regeneration scripts. Git history retains provenance.
They are not a fallback or a basis for new work.

New character presentation retains only the selected Jaska, young Aatami
front/side and Toko paper sources. See [the current register](APPROVALS.md) and
[design authority](../DESIGN_AUTHORITY.md). Aatami rigs and new motion still need
owner review. [CATALOG.md](CATALOG.md) links the retained sources.

Environment, equipment, animals, weather and isolated 3D pilot evidence remain.
Preservation does not promote any candidate or authorize new runtime models.
C.19 keeps its own procedural figures, miniature environments and tactical UI.
The city's structural CSS is compatibility code while its replacement is reviewed.
