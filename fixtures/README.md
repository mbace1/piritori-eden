# fixtures/

Ground-truth values dumped from the real, shipped implementation of a system —
not authored content (that's `content/`, `map/`, `art/`), and not a stand-in
for a real test.

**A fixture proves nothing by itself.** `people/roster.mjs`'s own header
already warns about this in as many words: *"a model that only ever sees its
own fixtures is a model that agrees with [itself]."* Every file here exists
because one specific number lives in exactly one place — usually tuned
GDScript with no equivalent in `COMBAT.md`'s prose — and a future
implementation needs the real value to match against, not a re-guess.

| File | Generated by | Ground truth for |
|---|---|---|
| `stance-weights.json` | `godot/tools/dump-stance-fixture.gd` | `COMBAT.md` §6.2's three stances have no numbers in the design doc — only `scripts/fight/fight_manager.gd`'s `stance_weight()` does |

**Regenerate, do not hand-edit.** Each file names its own generator. A stale
fixture is worse than none — it looks current.

**Read the generator's own header before using its output.** The stance table
in particular is a multiplier with nothing to multiply yet: `stance_weight()`
scores one command against a fighter inside a real command-scoring AI
(`_ai_select_command` in the same file), and no `battle`/`fight` model exists
in the JS house pattern (`market/model.mjs`, `missions/model.mjs`,
`people/roster.mjs`) to receive it as of 2026-08-28. The table alone will not
reproduce stance behaviour.
