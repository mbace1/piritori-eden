## Admission requirements

An attractive reference image or a Meshy SUCCEEDED status is insufficient. Each entry in `approved-manifest.json` must have:

1. Exact source image hashes and a consistent character style/identity.
2. Meshy task ID, model/settings and preserved raw GLB hash.
3. Inspection evidence for BOTH raw hands from front, back and oblique views: four distinct fingers plus a separate thumb, visible thickness, no bridges, loose fragments or intersecting digits.
4. A reduced derivative, initially targeting the existing approximately 15,000-triangle character budget, with its actual triangle count and hash recorded.
5. A second hand check on that reduced derivative. Reduced polycount must preserve digits and their gaps.
6. A dated review identifying the reviewed files, reviewer and outcome.

No entry inherits approval from new1/new2/new3, a different style variant, another model or an older task. Rigging/animation and game integration remain separate acceptance stages.
